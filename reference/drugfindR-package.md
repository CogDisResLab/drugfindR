# drugfindR: Drug Repurposing using Gene Expression Signatures

drugfindR is a package that allows users to perform drug repurposing
using gene expression signatures. It uses the LINCS L1000 signatures
available from iLINCS to find the most similar gene expression
signatures to the user's input signature. It then uses the connectivity
analysis to find the most similar drugs to the user's input signature.

## Details

drugfindR-package

The drugfindR package allows users to perform drug repurposing using
gene expression signatures. It uses the LINCS L1000 database to find the
most similar gene expression signatures to the user's input signature.
It then uses the connectivity analysis to find the most similar drugs to
the user's input signature.
